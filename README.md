🚨 AI-Powered Drug Trafficking Detection System
Cyber Armor | Smart India Hackathon (SIH) Submission

📌 Overview
Our project leverages Artificial Intelligence to detect and track drug trafficking activities across encrypted platforms like Telegram, WhatsApp, and Instagram. The system performs real-time monitoring, pattern recognition, and user behavior analysis to assist law enforcement in identifying and disrupting illegal drug networks.

🧠 How It Works
🔍 1. Data Monitoring
Continuously scans public data from messaging platforms, channels, and groups for suspicious content using APIs and scraping.

🧬 2. AI-Based Detection
Processes the collected data to detect drug-related keywords, patterns, user behaviors, and even bot activities.

🧾 3. User Tracking & Alerting
Traces key identifiers like IP addresses, phone numbers, and geolocation. Once confirmed, the system triggers an instant alert to law enforcement.

🧱 Core Pillars
Smart Surveillance – Real-time scanning across social platforms

Actionable Response – Generates alerts with detailed evidence
